# tinyshed research

The research grounds of the tinyshed projects: the measurements, prototypes
and dated reports behind their design decisions. Nothing here is a product
or a promise; a product's guarantees live in its own repository.

| Folder | Project |
|---|---|
| [tinystore/](tinystore/) | TinyStore, the embedded data runtime for Go on SQLite |

A number here is evidence for the day it was measured, with the machine,
versions, corpus and command that produced it. A later round supersedes an
earlier one by saying so, never by editing the number it replaces.
